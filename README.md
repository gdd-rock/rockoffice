# ⭐ RockOffice - AI Virtual Office 3D Simulation

A Minecraft-style 3D virtual office simulation built with Three.js. Features 21 AI bot employees with autonomous behaviors, pathfinding, and rich office interactions.

## ✨ Features

- 🏢 **Full office layout** (48×44 grid): CEO office, meeting room, medical room, server room, open workspace, gym, rest area, entertainment zone, bathroom, lobby
- 🤖 **21 AI bot characters** with autonomous behaviors: working, walking, meetings, gym, gaming, fishing, farming
- 🎮 **Minecraft pixel-block style** with Three.js 3D rendering
- 🗺️ **A* pathfinding** with smart rerouting when blocked
- 💬 **Inner monologue system**: Characters think and show speech bubbles
- ⚔️ **Interaction system**: Chat, argue, fight with injury → medical treatment
- 👑 **Boss mechanics**: Rocker visits injured employees, conducts office meetings
- 🐾 **Farm animals**: Cats, dogs, pigs, chickens, ducks, cows, sheep with wandering AI
- 🐟 **Fish pond** with colorful swimming fish
- 📺 **Business dashboard TV**: Real-time animated KPIs, revenue chart, global order heatmap
- 🏛️ **Grand reception**: Marble backdrop wall with company logo
- 👥 **Visitor system**: Auto-spawning interviewees and trainees
- 🚫 **Anti-clipping**: Collision detection, push-apart, smart rerouting

## 🚀 Quick Start

Just open `index.html` in any modern browser. No build tools, no dependencies, no server required.

```bash
# Or serve locally
npx serve .
```
